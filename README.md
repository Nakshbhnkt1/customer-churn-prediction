## 📈 Model Results

| Model | Accuracy | F1-Score | AUC |
|-------|----------|----------|-----|
| **Logistic Regression ⭐** | **80.48%** | **60.09%** | **0.842** |
| Random Forest | 78.64% | 55.14% | 0.827 |
| XGBoost | 78.57% | 57.10% | 0.821 |

## 🔍 Key EDA Findings

| Factor | Finding |
|--------|---------|
| Contract Type | Month-to-month = 42% churn vs Two-year = 3% |
| Tenure | New customers (0-10 months) = highest risk |
| Internet Service | Fiber optic = 33% churn vs DSL = 19% |
